ПРОЕКТ: ПОИСК АНАЛОГОВ ТОВАРОВ (HYBRID BM25 + RAG)

Цель: Интеллектуальный поиск похожих товаров по текстовому описанию с использованием гибридного подхода и генерацией отчетов на естественном языке (русский).

ОСНОВНЫЕ ВОЗМОЖНОСТИ
- Гибридный поиск: Сочетание классического поиска по ключевым словам (BM25) и семантического поиска через эмбеддинги (Sentence Transformers).
- Умное ранжирование: Использование алгоритма RRF (Reciprocal Rank Fusion) для объединения результатов.
- Локальная генерация отчетов: Формирование анализа аналогов с помощью компактных LLM (Qwen, Falcon), работающих локально.
- Очистка текста: Встроенная система исправления лексических ошибок и галлюцинаций для маленьких моделей.

БЫСТРЫЙ СТАРТ

1) Минимальный запуск (только поиск):
   python3 hybrid_bm25_rag.py --indices 0,10,20 --top-k 3

2) С генерацией отчета через Qwen (рекомендуется для слабых систем):
   python3 hybrid_bm25_rag.py --indices 0 --gen-report --llm-model qwen --hf-no-download

3) Запуск нескольких моделей для сравнения:
   python3 hybrid_bm25_rag.py --indices 0 --gen-report --llm-models qwen,falcon

СТРУКТУРА ПРОЕКТА

- hybrid_bm25_rag.py — основной пайплайн поиска и оркестрации.
- llm_report.py — логика формирования промптов, генерации и очистки отчетов.
- rag_core/ — ядро системы:
    - data.py: загрузка и нормализация CSV.
    - embeddings.py: управление моделями эмбеддингов и кэшированием.
    - components.py: сборка текстовых представлений товаров.
    - constants.py: пути и настройки по умолчанию.
- notebooks/ — интерактивные инструменты:
    - 00_setup.ipynb: проверка окружения и GPU (MPS).
    - 05_hybrid.ipynb: запуск полного цикла поиска и генерации.
    - 07_llm_report.ipynb: песочница для тестирования LLM-промптов.
- reports/ — сгенерированные текстовые отчеты.
- Best-Buy-dataset-clean.csv — исходные данные.

ПАРАМЕТРЫ ЗАПУСКА

--indices 0,10,20          Индексы товаров для анализа (из CSV).
--top-k 5                  Количество аналогов для поиска.
--gen-report               Включить генерацию LLM-отчета.
--llm-model NAME           Выбор модели (qwen, falcon, mistral).
--llm-backend transformers|http  Способ запуска LLM (локально через transformers или через API).
--hf-no-download           Использовать только ранее скачанные модели из кеша.
--allow-cross-category     Разрешить поиск аналогов в других категориях.

ОСОБЕННОСТИ РЕАЛИЗАЦИИ

1. Стабильность на слабых LLM: Система автоматически исправляет типичные ошибки маленьких моделей (например, "оператiva" -> "оперативной памяти") и принудительно форматирует отчеты.
2. Локальный кэш: Эмбеддинги для всего датасета вычисляются один раз и сохраняются в .npy файл, что ускоряет повторные запуски.
3. Apple Silicon: Проект поддерживает ускорение через MPS (Metal Performance Shaders) для вычисления эмбеддингов и инференса LLM.
